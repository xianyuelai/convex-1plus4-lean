## 2. 固定的定理与量词

主定理是 Theorem 1.1，标签 `thm:main`，TeX 行 72–74，PDF 第 1 页：

\[
\exists\delta_0>0\ \forall\mu\in\mathcal M\ \forall\varepsilon\in(0,\delta_0)\ \forall\text{有向逆时针壳序 }(0,\ell_1,\ell_2,\ell_3,\ell_4).
\]

其中 `M = { μ ∈ R⁴ : μᵢ > 0, ∑ μᵢ = 1 }`；质量为 `m₀ = 1`、`mᵢ = ε μᵢ`。结论是该壳序的**恰好一个**严格凸中心构型，模去平移、旋转、正尺度；反射不在等价关系内。六维形状空间上的约束 Hessian 非退化。`δ₀` 位于 `∀ μ` 之前，不能替换为 `δ₀(μ)`。

边界质量 `μᵢ = 0`、碰撞尺度 `t = 0`、`η = 0` 仅用于极限、除质量后的探针方程和光滑图；主定理仍只涉及正质量、非碰撞的严格凸构型。乘子固定为 1 是选取每个允许相似类的规范代表，不能将未归一化坐标误当作其形状空间。
